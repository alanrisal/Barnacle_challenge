Reference

Glossary

The terms used in every lesson. Lessons use these exact words. Grows as the course does.

Architecture

Two-stage detector
Stage one proposes candidate regions. Stage two classifies each one, refines its box and (in Mask R-CNN) predicts its mask. Mask R-CNN §3.
Backbone
The CNN that turns pixels into feature maps. Yours is ResNet-50 (R50).
FPN (Feature Pyramid Network)
Adds a top-down path to the backbone so every scale carries strong features. Outputs P2–P6.
P2 … P6
Pyramid levels with strides 4, 8, 16, 32 and 64 px. For a 640 tile, P2 is 160 × 160 × 256. Small barnacles live mostly on P2/P3.
Stride
How many input pixels one feature cell steps over. Stride 4 means one cell per 4 × 4 pixels.
Anchor
A reference box placed at every feature cell (one size per level × 3 aspect ratios). The RPN predicts objectness and a box shift for each one.
RPN (Region Proposal Network)
Stage one. Scores anchors for objectness and regresses them into proposals.
Objectness
The RPN's "is there any object here?" score. It is class-agnostic.
Proposal / RoI
A candidate box passed to stage two. RoI means region of interest.
NMS (non-maximum suppression)
Removes boxes that overlap a higher-scoring box above an IoU threshold. RPN uses 0.7; the final test pass uses 0.5.
RoIAlign
Extracts a fixed-size feature grid for a box by bilinear sampling, with no rounding to whole cells. Replaced RoIPool, whose rounding misaligns masks.
Box head
Stage two classifier + box regressor working on 7 × 7 RoIAlign features.
Mask head
Predicts a per-box binary mask. Standard Mask R-CNN: 28 × 28. Yours: PointRend.
PointRend
A mask head that predicts a coarse 7 × 7 mask and then refines it only at uncertain points, up to 224 × 224. Kirillov et al.
Coarse head
PointRend's lightweight head: a 14 × 14 grid of P2 features goes through a conv and a 2 × 1024 MLP and comes out as a 7 × 7 mask.
Point head
An MLP (3 × 256 hidden) applied per point. Its input is the P2 feature (256-d) plus the coarse prediction at that point.
Instance
One detected object: score + box + mask. Your output is a list of instances per tile.

Training

Loss terms
loss_rpn_cls, loss_rpn_loc (stage 1, the RPN); loss_cls, loss_box_reg (box head); loss_mask, loss_mask_point (PointRend). They are summed without re-weighting.
Iteration / step
One optimiser update on one batch. Your batch is one tile, so 600 steps = 600 tiles seen.
Detection cap
TEST.DETECTIONS_PER_IMAGE: maximum instances returned per image. Default 100; yours 600.
